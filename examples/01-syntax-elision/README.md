# G1 — syntax elision

Hide the markup, keep the content. Nothing is drawn in its place; the line simply closes up.
Rules: `g1-md-bold`, `g1-md-italic`, `g1-md-code-tick`, `g1-md-link-open`, `g1-md-link-target`,
`g1-json-key-quotes`.

What to look for: the asterisks are gone from the view and still in the file — select a whole line
and copy it, or run Find on `**`.
