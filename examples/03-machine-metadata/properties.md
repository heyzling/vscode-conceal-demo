# Property lines, in other tools' spelling

A paragraph Obsidian would anchor so it can be block-referenced. ^a1b2c3

- an item Logseq would give an identity
  id:: 6714b0f2-1f1c-4a55-9a1e-2c2f1f8a0b31
- another item
  id:: 3f2e1d0c-9b8a-4756-8f4e-1a2b3c4d5e6f

The Obsidian anchor sits at the end of a line and disappears cleanly. The Logseq property owns its
whole line, so hiding its text leaves an empty line behind — the same wall as
[07-line-elision](../07-line-elision/README.md).
