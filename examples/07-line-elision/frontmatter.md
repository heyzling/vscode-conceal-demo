# The blank-line problem

Four property lines above are concealed. Their text is gone and their lines are not: the file now
opens with four empty rows and a pair of `---`.

Hiding the text of a line that exists only for its text is worse than not hiding it at all. This is
the case that cannot be built on inline concealment, however the ranges are computed.
